# 1회차 · 읽기 마감재 (공유 버튼 + 집중 읽기 모드)

날짜: 2026-07-02
범위: 글 상세 페이지의 리더용 컨트롤 2종. 그래프·에디터·데이터는 건드리지 않는다.

## 배경

전체 기능 로드맵(13개 → 5회차)의 1회차. 위험 낮고 체감 큰 것부터.
설계 중 코드 확인으로 **B(이전/다음 글)는 이미 구현됨**(`[slug].astro:155-176` `post-nav`)을 발견해 제외.
**P(읽기 설정: 글자크기·폭·세리프)** 은 ROI가 낮아 보류(다음 회차로도 안 올릴 수 있음).

남은 1회차 항목:
- **A. 글 전체 공유 버튼**
- **N. 집중 읽기 모드 (N-a: 방해 요소 감추기)**

## 확정된 결정

1. **컨트롤 배치**: 우하단 세로 스택. 기존 `맨 위로` 버튼(`PostReading.astro`의 `.to-top`) 스타일을 재사용해 그 위에 쌓는다. 데스크톱·모바일 동일.
2. **집중모드 연출**: N-a(방해 요소 감추기). 스포트라이트(N-b)는 채택하지 않음(나중 확장 여지로만 둠).
3. **공유 동작**: `navigator.share` 지원 시 네이티브 공유 시트(모바일 등), 미지원 시 링크 클립보드 복사 + 버튼에 체크/완료 표시(소제목 링크복사와 같은 결).

## 컨트롤 스택 (우하단)

```
┌───┐
│ ⤢ │  집중모드 토글  (신규)
├───┤
│ ⤴ │  공유          (신규)
├───┤
│ ↑ │  맨 위로        (기존 .to-top)
└───┘
```

- 전부 `PostReading.astro` 안에 둔다(글 상세에서만 1회 포함되는 컴포넌트라 자연스러움).
- 원형 버튼 시각 스타일은 기존 `.to-top` 규칙을 공유(중복 CSS 최소화 — 공통 클래스로 묶고 아이콘만 다르게).
- **등장 규칙**:
  - `맨 위로`: 기존대로 스크롤 60vh 이상에서 노출(유지).
  - `공유`·`집중모드`: 항상 노출(글을 막 열었을 때도 공유·집중은 필요). 단 집중모드 진입 시엔 공유·맨위로는 숨기고 "집중 해제" 버튼만 남긴다.
- 모두 `aria-label` 부여, 키보드 포커스 가능.

## A. 공유 버튼 동작

- 클릭 시:
  - `navigator.share` 있으면 → `navigator.share({ title, url })` (title=글 제목, url=`location.href`). 사용자가 취소해도 조용히 무시.
  - 없으면 → `navigator.clipboard.writeText(location.href)` 후 버튼에 `.copied` 상태 1.5s(기존 heading-link 패턴 재사용). 클립보드 거부 시 조용히 무시.
- URL은 `location.href` 그대로(정적 페이지, 쿼리 없음).
- 새 의존성 0.

## N. 집중 읽기 모드 동작

- 토글 시 `document.documentElement`에 `data-focus="true"`/제거.
- **숨기는 것**(전역 CSS, `[data-focus='true']` 하위):
  - `.site-header` (BaseLayout)
  - `.site-footer` (BaseLayout)
  - 목차 3형태: `.toc-inline`, `.toc-aside`, `.toc`의 `variant="line"` 래퍼
  - 우하단 스택의 `공유`·`맨 위로` 버튼(집중모드 자체 버튼만 "해제"로 남김)
- **유지하는 것**: `.prose` 본문, 제목/설명/커버, 태그·연결·이전다음·댓글(글 흐름은 그대로 읽히게 — chrome만 제거).
- 진입 시 sticky 헤더가 사라지므로 `.prose h2/h3`의 `scroll-margin-top`은 그대로 둬도 무해.
- **해제 경로**: 집중모드 버튼 재클릭 + `Escape` 키.
- **상태 지속**: 세션/영속 저장하지 않는다(글마다 명시적으로 켜는 일시 상태). 페이지 이동 시 자연 해제.
- `prefers-reduced-motion`: 전환 애니 없이 즉시 토글(fade 정도만, 있으면 짧게).

## 재사용 / 최소 diff 원칙

- 버튼 시각: 기존 `.to-top` 스타일 공유(공통 클래스 도입).
- 공유 완료 표시: 기존 heading-link `.copied` 결.
- 숨김: 순수 CSS(`[data-focus]` 셀렉터) — JS는 토글·단축키만.
- 새 파일 없음. 변경은 `PostReading.astro`(버튼·스크립트·스타일)와, 전역 숨김 규칙 한 곳(BaseLayout 또는 PostReading의 `is:global`).
