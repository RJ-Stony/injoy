# 개편 진행표

2026-11-17 기준이다. 문서와 용어 통일은 `main`에, UI 개편은 `feat/overhaul`에 둔다. 규칙은 [AGENTS.md](../AGENTS.md)의 "UI 개편은 기능 브랜치에서"와 "일을 나누는 규칙"을, 세션별 상태는 [인수인계](handoff/)의 가장 늦은 파일을 따른다. 이 표에는 구현과 검증 상태만 적는다.

"대기"는 사용자의 결정을 기다리는 항목이다.

| 번호 | 항목 | 상태 | 다음 할 일 |
|---|---|---|---|
| O1 | 일을 나누는 규칙과 문서 틀 | 완료, `main`에 올림 | 없음 |
| O2 | 용어 후보 수집(글 40편) | 후보 표 작성 | 사용자가 표기를 정한다 |
| O3 | 용어 표기 결정 | 결정 완료 | [결정 문서](overhaul-terms.md)를 기준으로 O4 배정 |
| O4 | 용어 표기 적용과 글 다시 쓰기 | 글 40편을 `injoy-prose` 스킬로 다시 씀, 커밋 전 | 사용자가 글을 읽고 승인, 글마다 물음에 답해 도입과 맺음을 채운다 |
| O5 | 디자인 방향 결정 | 결정: 시리즈가 책 한 권인 서가, 밝고 광 없는 파스텔, 과슈 물감 표지 | [인수인계](handoff/2026-11-17.md)의 "사용자가 정한 것" |
| O6 | 디자인 구현 | 홈, 목차, 글, 머리말까지 `main`에 올림 | `/graph`, 용어 사전, 검색, 글쓰기 화면의 구조 |
| O7 | 전체 검증 | build, `scripts/verify.sh`, 이동 27가지 통과 | 배포된 화면에서 댓글 색, 실제 휴대폰 확인 |
