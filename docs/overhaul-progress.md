# 개편 진행표

2026-11-17 기준이다. 문서와 용어 통일은 `main`에, UI 개편은 `feat/overhaul`에 둔다. 규칙은 [AGENTS.md](../AGENTS.md)의 "UI 개편은 기능 브랜치에서"와 "일을 나누는 규칙"을, 세션별 상태는 [인수인계](handoff/)의 가장 늦은 파일을 따른다. 이 표에는 구현과 검증 상태만 적는다.

"대기"는 사용자의 결정을 기다리는 항목이다.

| 번호 | 항목 | 상태 | 다음 할 일 |
|---|---|---|---|
| O1 | 일을 나누는 규칙과 문서 틀 | 완료, `main`에 올림 | 없음 |
| O2 | 용어 후보 수집(글 40편) | 후보 표 작성 | 사용자가 표기를 정한다 |
| O3 | 용어 표기 결정 | 결정 완료 | [결정 문서](overhaul-terms.md)를 기준으로 O4 배정 |
| O4 | 용어 표기 적용 | 시작 전 | O3 뒤 글 묶음별로 워커에 배정 |
| O5 | 디자인 방향 결정 | 전면 개편으로 정함(엔진과 그래프는 유지), 세부 방향 대기 | 사례 조사 뒤 `DESIGN.md` 초안과 시안을 사용자가 고른다 |
| O6 | 디자인 구현 | 시작 전 | O5 뒤 화면별로 배정 |
| O7 | 전체 검증 | 시작 전 | build, `scripts/verify.sh`, 브라우저 확인 |
