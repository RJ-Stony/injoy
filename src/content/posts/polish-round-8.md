[[polish-round-7|지난 글]]에서 그래프를 자유롭게 해줬다. 이번엔 글 자체가 아니라 글의 *앞뒤*를 손보게 되었다. 발행하고 멍하니 기다리던 시간과, 다 읽고 난 뒤의 빈자리를 채워주는 과정이었다.

## 발행은 사실 이미 끝나 있었다

글쓰기 화면에서 발행을 누르면 글이 사이트에 뜰 때까지 1분쯤 멍하니 기다려야 했다. "배포 중…"이라는 문구만 돌았다.

그런데 생각해 보니 **커밋(GitHub에 글을 올리는 것)이 곧 발행** 과정으로 이어진다. 그 뒤 1분은 배포(올린 글을 사이트 화면으로 바꾸는 빌드)가 도는 시간일 뿐, 내가 붙잡고 있을 이유가 없었다.

```ts src/pages/write.astro
// 예전: 커밋한 뒤, 배포가 끝날 때까지 화면을 붙잡고 기다렸다
status.textContent = '배포를 기다리는 중…'; // [!code --]
const ok = await waitForDeploy(sha); // [!code --]
// 이제: 커밋되면 바로 끝났다고 알린다. 배포 확인은 뒤에서 알아서 한다.
status.textContent = '✓ 발행됐어요'; // [!code ++]
trackDeploy(sha); // 배포는 백그라운드로 확인하고, 끝나면 표시만 바꾼다 // [!code ++]
```

결국 "기다린다"를 "바로 끝내고 뒤에서 확인한다"로 바꾼 셈이다. 이제 발행을 누르면 곧장 "발행됐어요"가 뜨고 에디터가 바로 풀린다. 사이트에 반영됐는지는 작은 표시가 뒤에서 알려 준다. 멍때리던 1분이 사라졌다.

## 댓글을 받기로 했다

그동안 글은 일방통행이었다. 이제 글 아래에 댓글을 달 수 있다. giscus(GitHub의 토론 기능에 얹어 쓰는 댓글 도구)를 붙였다.

마음에 드는 건, 이 블로그가 *정적 사이트*(미리 만들어 둔 파일만 내보내는 방식)인데도 **서버도 시크릿 키도 없이** 댓글이 붙는다는 점이다. 댓글은 GitHub에 쌓이고, GitHub 계정으로 로그인하면 누구나 달 수 있다. 화면을 밝게·어둡게 바꾸면 댓글창도 같이 테마에 맞춰 따라온다.

## 시리즈로 묶고, 접어 두기

블로그를 다듬는 글이 어느새 여덟 편이다. 순서는 잡혀있긴 하지만, 나중에 이런 시리즈가 많이 생성될 수도 있기 때문에 이제는 **한 시리즈로 묶어** 글 아래에서 1편부터 차례로 보여 준다. 지금 몇 번째 글인지도 함께 보여 준다.

다만 글 밑에는 이미 연결된 글이며 만듦새며 들어찰 게 많았다. 그래서 시리즈는 평소엔 **접어 두고** 궁금할 때만 펼치게 했다.

## 작은 것 하나 더

코드 블록의 복사 버튼도 조금 똑똑해졌다. 고친 흔적을 보여 주는 코드(diff)에서 **지운 줄은 빼고 남는 코드만** 복사된다. 예전엔 지운 줄까지 통째로 복사돼, 그대로 붙여넣으면 어긋났다.

## 남은 것

글을 쓰는 쪽(발행)과 읽는 쪽(댓글·시리즈)을 한 번에 손봤다. 쓰면서 덜 기다리고, 읽고 나서 한마디 건넬 수 있게 바뀌었다. 댓글이 어떻게 쌓일지는 두고 봐야 알 것 같다. <span class="tossface">🌱</span>
