이 글은 Injoy에서 쓸 수 있는 마크다운 요소를 모두 모아 둔 스타일 점검용 글이다. 디자인을 손볼 때마다 이 글을 열어 고쳐야 할 곳이 없는지 확인한다. 글쓰기 문법이 궁금하다면
[이 블로그에 글 쓰는 법](/posts/how-to-write/)을 먼저 읽어 보자.

## 제목

제목은 `##`(h2)부터 쓴다. h1은 글 제목이 이미 차지했기 때문이다.
h2와 h3는 상단 목차에 자동으로 정렬된다.

### 셋째 단계 제목 (h3)

본문 안에서 소주제를 나눌 때 쓴다.

#### 넷째 단계 제목 (h4)

여기까지 내려오면 글을 쪼개는 편이 낫다.

## 문단과 강조

본문은 17~18px, 행간 1.8로 조판된다. **한 문단이 서너 줄을 넘기면 끊어 주는 것이
읽기에 좋다.** 강조는 **굵게**, 뉘앙스는 *기울임*, 정정은 ~~취소선~~, 코드 식별자는
`inline code`로 표시한다.

긴 영문이나 URL이 섞여도 `keep-all` 덕분에 한글 단어가 어색하게 끊기지 않는다.

## 목록

순서 없는 목록은,

- 첫 번째 항목

- 두 번째 항목

  - 들여 쓴 하위 항목

  - 하위 항목 하나 더

- 세 번째 항목

순서 있는 목록은,

1. 재료를 준비한다
2. 순서대로 조립한다
3. 빌드가 통과하는지 확인한다

체크리스트는,

- [x] 마크다운 파일 추가

- [x] frontmatter 작성

- [ ] 오타 검수

## 인용

> 기록은 미래의 나에게 보내는 편지다.
>
> 인용 블록은 왼쪽의 블루 라인과 옅은 배경으로 구분된다. 출처를 밝힐 때나
> 핵심 문장을 띄울 때 쓴다.

## 콜아웃

인용보다 강하게 눈길을 끌어야 할 때는 콜아웃을 쓴다. GitHub와 같은 문법이다.

```text
> [!NOTE]
> 이렇게 쓰면 콜아웃이 된다.
```

> [!NOTE]
> 참고. 본문 흐름에서 한 발짝 비켜서 알려 줄 내용에 쓴다.

> [!TIP]
> 팁. 알아 두면 좋은 요령이나 지름길

> [!IMPORTANT]
> 중요. 빠뜨리면 안 되는 주요 정보

> [!WARNING]
> 주의. 그냥 지나치면 문제가 생길 수 있는 내용

> [!CAUTION]
> 경고. 데이터가 날아가거나 되돌릴 수 없는 작업

## 코드

언어를 지정한 코드블록은 Shiki로 하이라이트되며 마우스를 올리면 복사 버튼이 나타난다.
라이트/다크 모드에 따라 팔레트가 자동으로 바뀐다.

```ts
// 한글 주석도 고정폭으로 가지런히 보인다
type Post = {
  title: string;
  pubDate: Date;
  tags: string[];
};

const byNewest = (a: Post, b: Post) =>
  b.pubDate.valueOf() - a.pubDate.valueOf();
```

```bash
# 셸 명령도 마찬가지
npm run build && npm run preview
```

긴 줄은 줄바꿈 없이 가로 스크롤로 처리된다.

```text
이 줄은 일부러 아주 길게 써서 코드블록의 가로 스크롤이 제대로 동작하는지 확인하는 용도의 줄이다. 화면이 좁다면 옆으로 밀어 보자.
```

### 줄 강조와 diff

코드 줄 끝에 `// [!code highlight]`를 붙이면 그 줄이 강조되며
`// [!code ++]` / `// [!code --]`를 붙이면 diff처럼 표시된다.
표기 자체는 렌더링 결과에서 사라진다.

```ts
const config = {
  site: 'https://injoy.example.com', // [!code --]
  site: 'https://rj-stony.github.io', // [!code ++]
  output: 'static', // [!code highlight]
};
```

## 수식

인라인 수식은 `$...$`로 쓴다. 질량-에너지 등가 $E = mc^2$ 처럼 문장 속에 자연스럽게 녹여쓸 수 있다.
블록 수식은 `$$`로 감싼다.

$$
\int_0^1 x^2 \, dx = \left[ \frac{x^3}{3} \right]_0^1 = \frac{1}{3}
$$

긴 수식은 가로 스크롤로 처리된다.

$$
f(x) = a_0 + \sum_{n=1}^{\infty} \left( a_n \cos \frac{n\pi x}{L} + b_n \sin \frac{n\pi x}{L} \right)
$$

## 글 연결

`[[슬러그]]`라고 쓰면 그 글로 가는 링크가 된다. 표시 텍스트를 따로 적지 않으면
제목이 자동으로 들어간다 — 이렇게: [[welcome]]. 파이프로 바꿔 부를 수도 있다:
[[welcome|첫 번째 글]].

위키링크는 단순한 링크가 아니다. 블로그의 [그래프](/graph/)에 "언급" 연결로
자동 수집되고, 글 하단의 **연결된 글** 목록에도 나타난다. 글이 쌓일수록
서로를 가리키는 그래프가 함께 자란다.

## 각주

본문 흐름을 끊지 않고 보충 설명을 달 때는 각주를 쓴다[^1]. 번호를 누르면
글 맨 아래의 각주로 이동하며 다시 본문으로 돌아올 수 있다[^2].

[^1]: 이렇게 글 어디에든 `[^1]: 내용` 형식으로 정의해 두면 맨 아래에 모인다.

[^2]: 각주가 길어지면 글을 나누라는 신호일 수도 있다.
