글이 열세 편이 되었다. 많다고 할 수는 없지만, 홈을 열면 글이 끝없이 아래로 이어졌다. 게다가 *블로그 다듬기 기록*처럼 한 줄기로 묶고 싶은 글들이 피드 여기저기 흩어져 있었다. 글이 더 쌓이기 전에, 쌓인 걸 어떻게 보여 줄지부터 손보기로 했다.

## 같은 시리즈는 폴더 하나로

가장 거슬린 건 시리즈였다. 같은 흐름의 글 여덟 편이 최신 글 사이사이에 끼어 목록을 길게 늘였다. 그래서 **시리즈로 묶인 글은 폴더 하나로 접어** 두고, 폴더를 누르면 그 자리에서 안의 글들이 펼쳐지게 했다.

먼저 글을 '시리즈에 속한 것'과 '낱개 글'로 갈랐다. 시리즈 글은 폴더로 가고, 나머지만 목록에 남는다. 결국 아래 함수가 하는 일은, 같은 `series`(글 머리에 적는 묶음 이름) 값을 가진 글을 두 편 이상일 때만 한 폴더로 모으는 것이다.

```ts
export async function getSeriesGroups() {
  const posts = await getPublishedPosts();
  const map = new Map();
  for (const p of posts) {
    if (!p.data.series) continue; // 시리즈 없는 글은 건너뛴다
    if (!map.has(p.data.series)) map.set(p.data.series, []);
    map.get(p.data.series).push(p);
  }
  return [...map.entries()]
    .filter(([, ps]) => ps.length > 1) // [!code highlight]
    .map(([series, ps]) => ({ series, posts: ps }));
}
```

폴더는 닫힌 채로 두고, 닫혀 있을 땐 가장 최근 글 제목을 옆에 살짝 보여 준다. 열면 안의 글이 읽는 순서대로, 읽는 시간과 조회수까지 같이 보인다. 폴더라는 비유를 끝까지 밀고 가니, 글이 폴더 안에 담긴 느낌이 났다.

## 목록은 열 개씩 끊어서

폴더로 묶어도 글은 계속 늘어난다. 그래서 홈도, 카테고리도, 태그 화면도 **처음 열 개만 보여 주고 나머지는 다음 페이지로** 넘기게 했다. 페이지네이션(긴 목록을 여러 쪽으로 끊어 보여 주는 것)인데, Astro에는 이걸 만들어 주는 도구가 있어 글 목록을 넘기면 알아서 페이지를 쪼갠다.

```ts
export async function getStaticPaths({ paginate }) {
  const posts = await getStandalonePosts();
  return paginate(posts, { pageSize: 10 }); // [!code highlight]
}
```

정적 사이트라 페이지마다 고유한 주소가 생긴다. 1쪽은 `/`, 2쪽은 `/2` 식이다. 검색 엔진이 모든 쪽을 따라올 수 있고, 화면도 가벼워진다. 지금은 글이 적어 아직 2쪽이 없지만, 늘어나면 자연스럽게 나뉠 것이다.

## 발행하는 순간을 조금 즐겁게

[[polish-round-8|지난 글]]에서 발행하고 멍하니 기다리던 시간을 없앴다. 이번엔 그 끝을 조금 더 즐겁게 했다. 배포가 끝나는 순간, 돌던 동그라미가 체크로 바뀌며 살짝 튀어 오르고 🌱이 함께 핀다. 글 쓰는 사람에게 보내는 작은 축하다. 움직임을 줄이는 설정을 켠 사람에겐 모션 없이 조용히 바뀐다.

## 그 김에 다듬은 것들

- **캡션**: 에디터에서 이미지 캡션(그림 아래 붙는 설명)을 이제 직접 적을 수 있다. 사실 발행 쪽은 진작 캡션을 그릴 줄 알았는데, 정작 쓰는 화면에 입력칸이 없었다. 조용히 비어 있던 칸을 채운 셈이다.
- **댓글**: 댓글창 색과 모서리를 블로그 톤에 맞췄다. 댓글은 여전히 깃허브 토론에 기대고 있어서 구조까지는 못 바꾸지만, 적어도 남의 옷처럼 튀지는 않게 됐다.
- **부드럽게**: 폴더든 시리즈 내비든, 펼치고 접힐 때 툭 끊기지 않고 스르륵 움직이게 했다.

마지막 건 의외로 한 줄에 가까웠다.

```css
details::details-content {
  block-size: 0; /* 닫히면 높이 0 */
  overflow: clip;
  transition: block-size 0.28s ease, content-visibility 0.28s allow-discrete; /* [!code highlight] */
}
details[open]::details-content { block-size: auto; } /* 열리면 실제 높이로 */
```

`::details-content`(펼쳐지는 영역만 따로 가리키는 새 CSS 선택자)와 높이를 '자동'까지 부드럽게 잇게 해 주는 설정 덕에, 자바스크립트 없이 여닫이가 매끈해졌다. 아직 이 기능을 모르는 브라우저에선 예전처럼 즉시 열린다. 망가지지 않고 그냥 덜 부드러울 뿐이다.

## 남은 것

인기순 정렬은 아직 *보고 있는 페이지 안에서만* 다시 줄을 세운다. 조회수가 사이트를 짓는 시점엔 없고 화면에서야 불러오기 때문인데, 글이 훨씬 많아지면 그때 다시 들여다볼 일이다. 쌓이는 걸 미리 겁내기보다, 쌓일 때마다 한 칸씩 정리하는 편이 나에게는 맞는 것 같다 🌱
